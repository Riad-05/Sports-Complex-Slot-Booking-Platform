## T-1: Creating a Receptionist Profile.
The admin can create and manage receptionist accounts by entering their basic information and assigning appropriate access to the system.
## T-2: Viewing Registered Profile
The admin can view a list of all registered users and access their basic account information for monitoring and management.
## T-3: Managing Sports Catagories
The admin can create, update, and organize different sports categories available in the sports complex, such as football, badminton or basketball.
