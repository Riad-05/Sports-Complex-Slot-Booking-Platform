## T-1: Creating a Receptionist Profile.
The admin can create and manage receptionist accounts by entering their basic information and assigning appropriate access to the system.
## T-2: Viewing Registered Profile
The admin can view a list of all registered users and access their basic account information for monitoring and management.
## T-3: Managing Sports Catagories
The admin can create, update, and organize different sports categories available in the sports complex, such as football, badminton or basketball.
## T-4: Viewing All Bookings
The admin can view all bookings made through the platform, including booking details, user information, selected sport, date, time and status.
## T-5: Viewing Revenue Reports
The admin can generate and review revenue reports to monitor the income earned from slot bookings.
## T-6: Setting Slot Schedules
The admin can create and manage available slot schedules by defining dates, times and the duration of each booking slot.
## T-7: Set Pricing
The admin can set or update the prices for different sports, courts or booking slots according to the requirements of the sports complex.
## T-8: Removing User Accounts
The admin can remove or deactivate user accounts when necessary, such as for invalid, inactive or unauthorized accounts.
## T-9: Viewing Booking Requests
The admin can review incoming booking requests and check their details before approving, rejecting or managing them.
## T-10: Viewing Booking Statistics
The admin can view statistical information about bookings, such as total bookings and user activity.
## T-11: Blocking Unavailable Slots
The admin can block specific slots when a court or facility is unavailable due to maintenance, private events or other reasons.
